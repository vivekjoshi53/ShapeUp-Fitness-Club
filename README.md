# ShapeUp Fitness Club

A responsive React website for ShapeUp Fitness Club in Hinjawadi, Pune.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm ci
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production-ready static site is generated in `dist/`. Deploy that directory to a static hosting provider such as GitHub Pages, Netlify, or Vercel.

## Contact form

The contact form opens a WhatsApp message to the club. The site does not submit form data to a server.
